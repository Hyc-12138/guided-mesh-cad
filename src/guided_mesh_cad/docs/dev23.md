## 原生交换与证书

`guided_mesh_cad.native_transport` 提供 `compare_native`、`assemble`、`verify_assembly`，返回执行结果、接受范围、完整报告和产物路径。计划 schema 为 `guided-mesh-cad.assembly.v1`，包含 units=mm、resources（id/path/sha256/scope）和 instances（id/resource_id/matrix）。全部路径相对计划文件；矩阵为有限 4×4 刚体矩阵。被排除内容需显式记录，完整性仅相对于调用者给定并冻结的计划。

范围、单位、实例名、原始变换、输入输出哈希、实际点证据与实现/运行时一起绑定。只检查所有列出的实例，不自动发现输入资料里未被列出的部件。不融合、重拟合、修补或暗改源形状。所需位姿和实际内核位姿共享同一线性误差预算，不能把两段 0.01 mm 累加成 0.02 mm。

真实点证书是一条明确的几何上界：目标点确实属于当前目标零件的原生边界，查询点到它的实际 XYZ 距离满足公差，则到该边界的最近距离不大于此值。它不是最近距离实测。每条证书绑定原生来源、叶子、位姿、顶点/边参数/面内 UV；不能从别的叶子借点，也不能在未裁剪底面或孔心造点。

## C0 与表示诊断

`guided_mesh_cad.representation` 区分原生序列化指纹、有限几何差异、积分估计与严格材料等价。方向向量读取时的浮点重正交化可能改变文本哈希；默认质量积分也可能对表示敏感，不能单凭任一结果判定模型损坏或材料完全相等。

`restrict_active_bspline` 是明确给定 bounds 的非周期 B-spline 曲线/曲面原语：复制后调用原生 Segment 限制参数域，不做近似拟合。调用者负责证明 bounds 覆盖所有实际使用域；有限点比对和原生算法记录不代替完整 BRep 拓扑/面边关系检查。周期输入和非法范围拒绝。`repair_representation` 对完整 BRep 的自动修复仍明确未实现。

## 验收与未覆盖项

最终发布凭据记录实际 wheel SHA、隔离安装路径、安装字节核对、旧接口回归、运行器故障测试及独立原生反例。开发源码测试不能替代安装包验证；候选 wheel 不自动成为已验收版本。

测试包括：源/产物/代码/运行时变更、DAG 失效、进程中断、锁冲突、损坏压缩证据、未知参数、巨大 Unicode/日志分页、无原生依赖读取状态、原生周期弧补集、孔心/体内点/错误零件、自由曲面、缺失/多余/改名实例、非刚体位姿。

有限采样不是连续全域 Hausdorff、严格材料集合、制造精度、无干涉或连续运动证明。基础有效性与完整 BOP/self-intersection 结论分开；已有材料布尔警告策略不放宽。窄面未命中内部采样会明确保留。POSIX 资源保护代码未在本 Windows 发布环境验证。

本包不包含任意网格自动分区、PDF/U3D 解码器或原始 CAD 特征历史恢复。
